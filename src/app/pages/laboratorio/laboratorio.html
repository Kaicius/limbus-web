1. Idempotência · X-Idempotency-Key

Todo POST precisa de uma chave única. Repetir a mesma chave não cria nada de novo.

  1. Clique em Enviar POST: a API cria o Sinner (201).
  2. Clique de novo, sem mudar nada: mesma resposta, com Idempotent-Replayed: true.
  3. Mude o nome e envie com a mesma chave: 422, a chave já foi usada com outro corpo.
  4. Clique em Enviar sem chave: 400, o cabeçalho é obrigatório.

4. CORS

Este front roda em {{ origem }} e a API em {{ apiUrl }}: são origens diferentes. O navegador só entrega as respostas porque a API devolve Access-Control-Allow-Origin para as origens listadas em app.cors.allowed-origins. Se esta origem não estiver na lista, todas as telas mostram "Não foi possível falar com a API".
